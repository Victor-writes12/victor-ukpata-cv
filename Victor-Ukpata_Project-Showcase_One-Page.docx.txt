1) Grandeur Structure Limited — Corporate Website
- Client: Grandeur Structure Limited
- Period: 2024
- Challenge: No modern web presence; prospective clients had limited information about services.

- Tech: HTML, CSS, GitHub Pages, Figma

2) CRM Automation — Customer Communication Workflow
- Client: Small businesses (multiple clients)
- Period: 2023 – 2024
- Challenge: Manual follow-ups, inconsistent client communication, and increased support workload.
- Solution: Implemented automated workflows (CRM rules & templated responses), set up canned replies and knowledge-base articles, and trained staff on usage.
- Result: Faster and more consistent responses; reduced manual follow-up time and fewer repeat support queries.
- Tech: Freshdesk (or similar), workflow automation, documentation

4) Technical Documentation & Onboarding Guides
- Scope: Multiple clients / internal workflows
- Challenge: New users required repeated help to perform basic tasks.
- Solution: Wrote user-friendly manuals, quick-start guides, and knowledge-base articles using clear step-by-step instructions and screenshots.
- Result: Faster onboarding and fewer repetitive support tickets; staff can follow consistent procedures.
- Tools: Markdown, Google Docs, Snagit for screenshots
